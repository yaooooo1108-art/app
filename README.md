這次專案使用 Android Studio 與 Kotlin 開發員工排班系統，整合首頁公告、會員中心、每週排班設定、排班結果及個人頭像拍攝等功能，並透過 BottomNavigationView 與 ViewPager2 實現頁面切換及左右滑動操作。此外，我也嘗試加入中英文多國語言介面，讓應用程式能依照手機系統語言自動切換顯示內容，提升使用上的便利性。

透過這次專案，我學習到如何運用 Kotlin 撰寫程式、使用 XML 設計介面，以及透過 Fragment 管理不同頁面的功能。我也進一步了解 ViewModel 的資料傳遞方式、CameraX 的相機操作，以及字串資源與多國語言的設定。在開發過程中，我遇到許多程式錯誤與功能整合上的問題，透過檢查程式碼、分析錯誤訊息及反覆測試，逐漸提升了自己的除錯能力與解決問題的能力。

這次經驗讓我明白，開發一個完整的應用程式不只是讓功能正常運作，還需要考慮程式架構、操作流程與使用者體驗。未來無論是進行課程作業、團隊專題或投入資訊相關工作，這些實作經驗都能幫助我更有系統地規劃功能、整合不同技術並處理開發過程中的問題。我也希望未來能繼續學習資料庫整合、使用者登入及雲端資料同步等技術，進一步提升自己的程式開發能力，為未來的專題製作與職涯發展奠定更扎實的基礎。
